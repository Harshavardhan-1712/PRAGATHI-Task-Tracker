# PRAGATHI – Task Tracker
## Submission Note

**Project:** PRAGATHI – Task and Productivity Management System  
**Technology Stack:** Core PHP, MySQL, HTML, CSS, JavaScript, Bootstrap and Chart.js

### 1. Basic Level – Core Requirements
- User registration and authentication.
- Create, view, update and delete tasks.
- Task status management.
- Task search and filtering.
- MySQL database integration.
- Secure database operations using PDO prepared statements.

### 2. Intermediate Level – Extended Functionality
- Task priorities and deadline management.
- Kanban board for visual task tracking.
- Calendar-based task organization.
- Task categories.
- Dashboard with productivity statistics.
- Activity history and notifications.
- Pagination and bulk task operations.

### 3. Advanced Level – Additional Enhancements
- Productivity analytics and visual charts.
- Task archiving and restoration.
- CSV task export.
- User-specific task ownership and access control.
- CSRF protection and input sanitization.
- Responsive interface for different screen sizes.

### 4. Submission Contents
- Complete PHP source code.
- MySQL database schema and SQL file.
- README with installation and configuration instructions.
- Application screenshots.
- Project documentation.
